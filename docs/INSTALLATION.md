# V2A Installation Guide

Welcome to **V2A — Video to Audio Converter & Studio** (v1.2.0).  
This guide explains how to install V2A on **Windows 10/11** and **macOS**.

---

## 🪟 Windows 10 / 11 Installation

### Option 1: Standard Installer (Recommended)
1. Download **`V2A-Setup-1.2.0-x64.exe`** from [GitHub Releases](https://github.com/margacis2/v2a/releases).
2. Double-click the installer.
3. Follow the setup wizard to choose your installation directory (default: `C:\Program Files\V2A`).
4. Optionally choose to create a desktop shortcut.
5. Click **Install**.
6. Launch V2A from your Start Menu or Desktop shortcut.

### Option 2: Portable Edition (No Installation Required)
1. Download **`V2A-1.2.0-Windows-x64-Portable.zip`**.
2. Extract the ZIP to any folder (e.g. `C:\Tools\V2A` or a USB drive).
3. Double-click **`v2a.exe`** to launch immediately.

---

## 🍎 macOS Installation

### Option 1: Apple Disk Image (DMG)
1. Download **`V2A-1.2.0-macOS.dmg`** from [GitHub Releases](https://github.com/margacis2/v2a/releases).
2. Double-click the DMG to open it.
3. Drag the **V2A** icon into your **Applications** folder.
4. Launch V2A from Launchpad, Spotlight, or the Applications folder.

### Option 2: Apple Package Installer (PKG)
1. Download **`V2A-1.2.0-macOS.pkg`**.
2. Double-click the PKG installer and follow the on-screen steps.
3. The app is automatically installed into `/Applications/V2A.app`.

---

## ⚙️ Initial Setup & Verification

Upon first launch:
1. V2A will verify the presence of FFmpeg on your system.
2. If using the Complete Edition, the bundled FFmpeg is automatically activated.
3. If using the Lite Edition, V2A will detect your system PATH FFmpeg. (See [FFmpeg Setup Guide](FFmpeg_SETUP.md) if needed).
4. You are ready to drag and drop video files and export high-fidelity audio!
